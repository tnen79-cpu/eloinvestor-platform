# إلو مستثمر — v73

نسخة مطورة فوق `alo_v72_translation_editor_fix.zip`، مع الحفاظ على الحسابات والباقات والتوثيق والمحادثات والإدارة الموجودة.

## التعديلات

- الرئيسية: مسارات واضحة لتصفح الفرص، عرض مشروع، والبحث حسب متطلبات المستثمر، مع أسئلة شائعة توضح التوثيق والعائد.
- البحث: دمج فلاتر شريط البحث والفلاتر الجانبية دون فقد الخيارات، حفظها في الرابط، واستعادة الخيارات عند الرجوع في المتصفح.
- إصلاح اختلاف التصنيفات بين التخزين بالإنجليزية والبحث بالعربية.
- التصفح: 12 فرصة لكل صفحة، وجلب البيانات بنطاقات متتابعة لتجاوز حد النتائج الافتراضي.
- التفريق بين فشل الاتصال وبين عدم وجود فرص مطابقة، مع إعادة المحاولة.
- المقارنة: اختيار مشروعين أو ثلاثة، جدول السعر والربح والموقع والتوثيق، ورابط قابل للمشاركة. تُحفظ معرفات الاختيار في جلسة المتصفح فقط، ويُعاد جلب بيانات المشاريع المنشورة عند فتح المقارنة.
- صفحة `find-project.html`: بحث بالمجال والموقع ونوع الفرصة وأقصى ميزانية؛ لا ترسل طلبًا إلى موظف أو معلن.
- العائد: عند توفر السعر والربح الشهري، الربح الشهري × 12 ÷ السعر × 100. عدم وجود السعر لا يحول مبلغ الربح إلى نسبة. الربح الصفري يظهر 0%، والمفقود يظهر غير متاح.
- التوثيق: شارة المقارنة وبطاقات السوق تعتمد على `verification_status = verified` فقط.
- الحفظ: لا تظهر رسالة نجاح إذا رفضت قاعدة البيانات العملية.
- الرئيسية: استبدال عداد «مستثمر نشط» غير المثبت بعدد القطاعات المتاحة، وتوضيح أن مجموع الأسعار هو قيمة الفرص المدرجة. النشاط العام يستخدم المشاريع المنشورة، ولا يعرض إشعارات المستخدمين الشخصية.
- تنسيق متجاوب، فصل زر الحفظ عن رابط الصورة، ودعم العربية والإنجليزية للنصوص الثابتة الجديدة.
- تحديث إصدار JavaScript إلى 73 لكسر كاش الملفات المعدلة.

## الاستخدام

هذه الملفات تعديل للمشروع القائم وليست موقعًا منشورًا جديدًا. ارفع الصفحات ومجلد `assets` كاملًا إلى استضافة المشروع عند اعتماد النسخة. لا توجد ترقية SQL جديدة في v73. تظل إعدادات قاعدة البيانات وترقيات SQL السابقة مطلوبة للميزات القديمة.

لا تحتاج ملفات `tests` أو `package.json` أو `package-lock.json` إلى النشر؛ هي للتحقق المحلي فقط. تستمر الصفحات بالعمل بصيغة HTML/CSS/JavaScript كما في النسخة السابقة.

للاختبار المحلي باستخدام Node 20.19 أو أحدث:

```sh
npm ci
npm test
```

## التحقق المنفذ

- نجاح فحص Syntax لكل ملفات JavaScript.
- نجاح اختبار قواعد حساب العائد، التصنيفات، التوثيق، حدود السعر والترتيب.
- نجاح اختبارات DOM للفلاتر المدمجة، إزالة شرط التوثيق، تحميل 501 نتيجة بنطاقين، التنقل بين الصفحات، اختيار المقارنة، إخفاء غير المنشور، تهريب النصوص في المقارنة، وفشل التحميل والحفظ.
- نجاح فحص روابط الملفات المحلية وترجمات النصوص الجديدة وملفات JSON.
- نجاح استعلام قراءة للفرص المنشورة من قاعدة البيانات القائمة باستخدام المفتاح العام.

لم يتم تغيير قاعدة البيانات، أو تنفيذ عمليات كتابة حقيقية، أو نشر النسخة. اختبارات DOM لا تثبت المظهر المرئي على جهاز حقيقي. ما زال اختبار التسجيل والمحادثات والمدفوعات والتوثيق والصلاحيات بالكامل على بيئة تشغيل مطلوبًا قبل إعلان الجاهزية للإنتاج.
