# v40 Admin Ads Panel

تم إضافة قسم "الإعلانات" داخل لوحة الإدارة.

المضاف:
- عنصر جديد في Sidebar: الإعلانات
- عرض كل الإعلانات من جدول platform_ads
- إضافة إعلان جديد
- تعديل إعلان
- تفعيل / إيقاف إعلان
- حذف إعلان
- معاينة الإعلان داخل نموذج الإدارة
- ربط السلايدر في الرئيسية بإعلانات placement = home_top فقط
- فلترة الإعلانات المنتهية حسب starts_at / ends_at

مهم جداً:
شغّل الملف التالي في Supabase SQL Editor بعد v39:

supabase/v40-admin-ads-panel.sql

حتى تعمل صلاحيات الإضافة والتعديل والحذف من لوحة الإدارة.
