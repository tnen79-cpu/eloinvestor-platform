نسخة إلو مستثمر v12 Pro Upgrade

تم في هذه النسخة:
- تسريع تحميل الصفحات عبر App Loader ذكي حسب الصفحة بدل تحميل كل السكربتات.
- Dashboard بسايدبار حسب نوع الحساب.
- صاحب المشروع: مشاريعي، إضافة مشروع، الإحصائيات، طلبات المستثمرين، الباقات، الإشعارات، النشاط، الملف الشخصي.
- المستثمر: الفرص المقترحة، الاهتمامات، التوثيق، المحفوظات، تواصلت معها، الإشعارات، النشاط، الملف الشخصي.
- تفعيل حفظ المشروع وإزالته.
- تفعيل سجل تواصلت معها وإزالته.
- تفعيل إشعارات محلية داخل اللوحة.
- تفعيل Activity Timeline محلي داخل اللوحة.
- تحسين شكل التوصيات ونسبة الملاءمة وأسباب المطابقة.
- تحسين CSS للوحة والبطاقات والموبايل.
- إضافة ملف Supabase اختياري: supabase/v12-pro-upgrade.sql

ملاحظة:
بعض الميزات تعمل محليًا عبر localStorage حتى لو لم تشغّل SQL. لتثبيتها في قاعدة البيانات مستقبلاً شغّل ملف SQL ثم نربط القراءة/الكتابة بالكامل مع Supabase.
