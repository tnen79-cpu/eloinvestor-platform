إلو مستثمر v28 - Full Verification Suite

ما تم إضافته فعليًا:
- فلترة وبحث داخل مركز التوثيق.
- بيانات صاحب الطلب بجانب كل ملف.
- صفحة تفاصيل طلب التوثيق داخل Drawer.
- Risk Score لكل طلب.
- حالات احترافية: pending / under_review / verified / rejected / needs_documents / suspicious / expired.
- ملاحظات الإدارة بدون الاعتماد على prompt عند فتح التفاصيل.
- Timeline من admin_activity_logs.
- إشعارات لصاحب الطلب عند تغيير الحالة إذا جدول notifications موجود.
- تحديث شارة المشروع/المستخدم عند قبول التوثيق.

قبل الاستخدام:
1) شغّل supabase/v28-full-verification-suite.sql
2) افتح admin-dashboard.html > التوثيق
3) اضغط "تفاصيل التوثيق" لأي ملف.
