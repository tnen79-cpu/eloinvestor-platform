# إلو مستثمر — v75

اقرأ هذا الملف قبل التشغيل. هذه النسخة تكمّل v74، ولم تُنشر أو تُطبّق ترقياتها على قاعدة Supabase الفعلية لعدم توفر صلاحية إدارية للمشروع في الاتصال الحالي.

## التغييرات

- **نشر المشروع في معاملة واحدة**: إنشاء المشروع وصفوف الصور ومستندات التوثيق وخصم رصيد واحد عبر `publish_project_v75`. أي فشل في العملية يعيد تغييرات قاعدة البيانات كاملة. معرّف الطلب ثابت عند إعادة محاولة نفس البيانات والملفات، ويمنع تكرار النشر أو خصم الرصيد.
- **تعديل المالك**: إصلاح تحميل صفحة تعديل المشروع، وحفظ التعديل عبر API يعيد المشروع للمراجعة دون خصم رصيد جديد. مقارنة النسخة السابقة تمنع حفظ تغيير فوق تعديل أحدث. منع تعديل المشروع المنشور مباشرةً لتجاوز المراجعة.
- **باقات حقيقية من الإدارة**: واجهة الباقات تقرأ `admin_plans` بدل الأسعار والأرصدة الثابتة المختلفة عن الإدارة. أضيفت حقول الرصيد المميز وبيانات التحويل المعتمدة إلى محرر الإدارة. الباقة التي لا تحتوي بيانات تحويل حقيقية لا يمكن شراؤها. حُذفت بيانات البنك التجريبية.
- **طلب الدفع**: السعر والرصيد والمدة تُحددها قاعدة البيانات. النسخة المعروضة للمشتري تُقارن بالبيانات الحالية قبل إنشاء الطلب؛ تغير السعر أو بيانات التحويل يتطلب إعادة التحميل. تثبيت نسخة شروط الباقة عند إنشاء الطلب، ومنع إعادة المحاولة من إنشاء طلب إضافي.
- **قرارات الدفع**: قبول الطلب يضيف الرصيد مرة واحدة. لا يمكن قبول طلب مرفوض أو رفض طلب تم تفعيله. الطلبات القديمة التي تفتقد نسخة شروط موثقة لا تُقبل تلقائيًا؛ تحتاج مراجعة وإعادة إنشاء طلب صحيح. صفحة `payments.html` تعرض حالة الطلب وملاحظة الإدارة.
- **محادثات مترابطة**: الرسالة وعداد المحادثة والإشعار تُحفظ في معاملة واحدة. إعادة الطلب لا تكرر الرسالة أو العداد. رفض إرسال رسالة في محادثة مغلقة أو من طرف خارجها، ومنع تغيير هوية أطراف المحادثة أو الرسالة. النص الذي يكتبه المستخدم أثناء الإرسال لا يُحذف بعد وصول الرد.
- **ملفات خاصة**: إيصالات الدفع ومستندات التوثيق ومرفقات المحادثات في buckets خاصة، بروابط موقعة قصيرة العمر. مرفقات المحادثة تُفتح لطرفيها أو الإدارة المخولة؛ الإيصالات والمستندات للمستخدم والإدارة المختصة. يدعم قارئ الملفات الروابط القديمة الخاصة بـSupabase إلى جانب المراجع الجديدة `storage://...`.
- **تصفح عام محدود**: `marketplace_projects` يعرض حقول الإعلان دون رقم الواتساب أو ملاحظات الإدارة. بيانات التواصل تُطلب بعد تسجيل الدخول. قراءة المشاريع غير المنشورة مقيدة بالمالك والإدارة المخولة. الصور العامة مخصصة لمحتوى الإعلان؛ لا تُرفع ملفات شخصية فيها.
- **التسجيل والتحميل**: منع كتابة/إعادة تعيين الملف الشخصي إذا لم ينشأ تسجيل دخول بعد تأكيد البريد، وعدم اختلاق ملف شخصي عند فشل قاعدة البيانات. قصر روابط ما بعد الدخول على صفحات داخلية معروفة، وإغلاق مؤقتات الاتصال. تعذر تحميل ملف JavaScript أساسي يظهر إعادة محاولة ويمنع إرسال النماذج بالطريقة الأصلية للمتصفح.
- إصلاح ربط صفحة التوثيق بمنطقها. التوثيق فيها للحساب؛ مستندات المشروع مرتبطة بمشروع محدد أثناء النشر، بدل قبول طلب مشروع غير مرتبط بأي مشروع.
- تحديث رابط تحميل التطبيق في جميع الصفحات إلى v75، وإضافة تهريب النصوص إلى عارضات قديمة للمستندات.

5. `supabase/migrations/20261011230900_project_edit_review.sql`

هذه ملفات ترقية للمشروع القائم، وليست تأسيس قاعدة جديدة من الصفر. لا تستخدم `db reset` عليها. جرّب الترقيات والنسخة معًا في بيئة تجريبية أولًا، ثم انقلها للإنتاج ضمن تحديث منسق: ترقية الملفات الخاصة تغيّر وصول الروابط القديمة، والواجهة الجديدة تعتمد على view وRPCs الجديدة. رفع ملفات HTML فقط دون SQL سيعطل المسارات التي تحتاجها. لم تُختبر الترقيات على مخطط القاعدة الفعلية أو تُشغل Advisors عليها لأن الوصول الإداري مرفوض.

دوال الجاهزية تمنع رفع الملفات الخاصة أو بدء العمليات الحساسة إذا لم تتوفر الحماية المطلوبة. لتمكين شراء الباقات، يدخل موظف مخول بيانات تحويل حقيقية في لوحة الإدارة؛ لا يتم افتراض بيانات حساب مصرفي.

## إعادة المحاولة والتخزين

الملفات تُرفع إلى Storage قبل معاملة قاعدة البيانات. المعاملة تعيد صفوف قاعدة البيانات عند الفشل، لكنها لا تمحو ملفات Storage التي رُفعت عبر HTTP. تبقى هذه الملفات قابلة لإعادة الاستخدام عند محاولة نفس الطلب، وقد يلزم تنظيف الملفات غير المرتبطة بعد التشغيل. لا توجد مهمة تنظيف آلية في هذه النسخة.

تستخدم مفاتيح إعادة المحاولة بصمات SHA-256 للملفات وبيانات العملية. تُحفظ المفاتيح في جلسة المتصفح، دون تخزين محتويات الإيصال أو مستند التوثيق محليًا. توجد ذاكرة احتياطية للمحاولة داخل الصفحة إذا تعذر التخزين المحلي؛ تحديث الصفحة في هذه الحالة قد يفقد مفتاح المحاولة.

## الاختبارات

نجحت 9 مجموعات اختبارات محلية، تشمل:

- الحسابات والفلاتر والمقارنة ومساحة المتابعة السابقة.
- التسجيل الآمن، الروابط الداخلية ومؤقتات الاتصال.
- فشل تحميل ملف أساسي ومنع الإرسال الأصلي للنماذج.
- حدود أنواع/أحجام الملفات، حماية الرفع، مفاتيح الطلب وإعادة محاولة النشر.
- عرض الباقات من بيانات الإدارة وإرسال الطلب دون اعتماد قيم رصيد/سعر غير موثقة.
- SQL عبر PostgreSQL محلي (PGlite): التراجع عند فشل حفظ مستند بعد إنشاء المشروع، خصم رصيد مرة واحدة، طلب دفع واحد، تفعيل واحد، رفض شروط سعر معدلة، رسالة واحدة وعداد واحد، صلاحيات المرفقات، تعديل المالك دون خصم إضافي، ورفض التعديل القديم والقراءة العامة لمعلومات التواصل.

```sh
npm ci
npm test
```

الاختبارات المحلية ليست اختبار E2E على Supabase الحقيقي، ولا تحققًا مرئيًا على أجهزة الموبايل. ما زال تطبيق SQL، اختبار حسابين مختلفين وأدوار الإدارة، وفحص المسارات كاملة والواجهات على بيئة تشغيل مطلوبًا قبل إعلان الجاهزية للإنتاج. لم يُنفذ تحويل بنكي أو إرسال رسالة حقيقية أو تسجيل حساب فعلي خلال هذه الجولة.
